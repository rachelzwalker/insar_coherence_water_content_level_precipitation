# InSAR_Coherence_Water_Content_Level_Precipitation

## Name
InSAR Coherence analysis with water level, soil moisture (water content) and precipitation data

## Description
InSAR Coherence Sentinel-1 data acquisition and then analysis with ground data (water level, soil moisture and site-level precipitation) and regional precipitation data.

Analysis involves rolling windows of 1 month, 6 weeks and 2 months with outputs including Pearson and cross correlations.
